## homedit 0.3.0

A new web app, built in Rust on the Krifmaz kit, with the Encore look. Everything the dashboard and editor did before still works the same way.

- **Settings, Diagnostics, What's new and Bug reports pages** for admins, from the server's kit API.
- **Updates itself.** A new version reloads the page on its own, but never while edit mode is open.
- **Notices** at the top of the page when the data folder can't be written or Docker can't be reached.
- **Works offline.** A banner says when the server can't be reached, and the page keeps showing what it had.
- **Crash logs.** If the page breaks, the error is sent to the server for admins to read, later if it is offline.
- **Clear confirmations and toasts.** Questions such as "Scan 10.0.1.0/24 instead?" use the kit's dialog, and every error toast has a Copy button.
- **Keyboard reordering** is now Alt+arrow keys on a focused card, group or bookmark.
