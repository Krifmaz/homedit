## homedit 0.1.0

The first release: a self-hosted homelab dashboard with a built-in editor.

- **Dashboard and editor.** Groups, services and bookmarks, edited in place with drag and drop, undo and redo, and a version history.
- **Sign-in.** Local accounts, single sign-on (OpenID Connect) or a trusted reverse proxy; API keys and passwords are stored encrypted.
- **Widgets.** Plex, Jellyfin, Immich, the *arr apps, qBittorrent, SABnzbd, Proxmox, Portainer, Pi-hole, AdGuard Home, Uptime Kuma and more.
- **Find services.** A network scan that recognises apps, Docker label discovery, and import from gethomepage.
- **Backups.** Export and restore the whole dashboard as one YAML file.
