## homedit 0.2.0

The server now speaks the Krifmaz kit's shared API: the groundwork for the new web app in the next release.

- **Server settings from one table.** Sign-in, single sign-on, reverse proxy, network, Docker and scan settings can be saved through the API as well as set by environment variables, which still win. Saved changes take effect after a restart.
- **Diagnostics.** Checks for the data folder, the database, the secret key, Docker and single sign-on, each saying how to fix what's wrong.
- **Notices.** A plain warning when the data folder can't be written or Docker can't be reached, checked again every minute.
- **Bug reports and crash logs.** Reports with screenshots and an admin reply thread, kept on the server.
- **What's new.** Release notes like these, served for the web app to show once after each update.
